# Aditya Kumar Singh's GitHub Profile Repository

Welcome to the configuration and asset repository powering [@ADITYAKUMARSINGH16](https://github.com/ADITYAKUMARSINGH16)'s GitHub Profile page.

## 📁 Repository Structure
- `README.md` - The rendered GitHub profile landing page.
- `index.html` - The interactive Profile Studio & Live Generator tool for real-time markdown customization.
- `.github/workflows/snake.yml` - Automated action that generates the contribution grid snake game SVG every 12 hours.
- `.github/workflows/recent-activity.yml` - Automated action that updates recent public repository activities daily.

## 🛠️ GitHub Actions Setup Note
To ensure automated SVG contribution graphs and activity workflows can push commits:
1. Go to repository **Settings** > **Actions** > **General**.
2. Under **Workflow permissions**, select **"Read and write permissions"**.
3. Save changes.
